做题技巧

🔑 关键词

重点关注 however、but、because、therefore、数字、时间。

高频陷阱

⚠️ 转折

尤其注意说话人先提出一个观点，然后通过 but / however 修改答案。

🎯 听力口诀

数字：价格、日期、时间、数量。
转折：but / however / although 后面非常重要。
因果：because / therefore / so / as a result。
态度：really? / actually / unfortunately / surprisingly。

✍️ 写作训练

✍️ SIM EPT 写作框架

考试中不要追求复杂到无法控制的句子。先保证结构清晰、语法正确。

Part 1

开头

Nowadays, ...

It is widely believed that ...

In recent years, ... has become increasingly important.
Part 2

观点

In my opinion, ...

I believe that ...

There are several reasons for this view.
Part 3

论证

One important reason is that ...

Another factor is that ...
Part 4

举例

For example, ...

For instance, ...
Part 5

结果

As a result, ...

Therefore, ...

Consequently, ...
Part 6

结尾

In conclusion, ...

To sum up, ...

Taking everything into consideration, ...
