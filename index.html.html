📚 语法知识点

点击任意知识点查看讲解、结构、例句、易错点和练习答案解析。

语法

一般现在时

主语 + 动词原形；第三人称单数通常加 -s/-es

语法

一般过去时

主语 + 动词过去式；否定用 did not + 动词原形

语法

一般将来时

will + 动词原形；be going to + 动词原形

语法

现在进行时

am/is/are + doing

语法

过去进行时

was/were + doing

语法

现在完成时

have/has + 过去分词

语法

过去完成时

had + 过去分词

语法

主将从现

If/When/Before/After/As soon as + 一般现在时；主句 + will + 原形

语法

虚拟条件句

现在相反：If + 过去式, would + 原形；过去相反：If + had done, would have done

语法

情态动词

情态动词 + 动词原形

语法

被动语态

be + 过去分词

语法

主谓一致

谓语形式必须与主语的人称和数一致

语法

定语从句

先行词 + who/which/that + 从句

语法

宾语从句

主句 + 引导词 + 陈述语序

语法

非谓语动词

to do / doing / done

语法

比较级

短形容词 + er / more + 长形容词，常与 than 搭配
